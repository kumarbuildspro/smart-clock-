# Digital Clock 🕐

A beautiful, responsive digital clock web application built with HTML, CSS, and JavaScript. Features a modern design with glowing neon effects and works as a Progressive Web App (PWA).

## Features

✨ **Live Digital Clock** - Real-time display of hours, minutes, and seconds
📅 **Date Display** - Shows current date with day of the week
🎨 **Modern Design** - Gradient background with neon glow effect
📱 **Fully Responsive** - Works perfectly on desktop, tablet, and mobile devices
🚀 **Progressive Web App** - Can be installed as a standalone app
⚡ **Lightweight** - No dependencies, pure vanilla JavaScript

## Files Included

- **index.html** - Main HTML structure with clock display container
- **style.css** - Styling with gradient background, animations, and responsive design
- **script.js** - JavaScript functionality for real-time clock updates
- **manifest.json** - PWA manifest for app installation support
